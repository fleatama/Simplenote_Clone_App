# ポートフォリオ撮影用 デモノート文言セット（全10件）

作成日：2026-11-02
用途：Simplenoteクローンのスクリーンショット撮影前に、デモ用アカウントへコピペで投入するための文言集。本文は各コードブロックの中身をそのまま貼る想定（Simplenote系は1行目がタイトルになる）。

## 投入のコツ

- 一覧は「更新した順」で上に来る想定。**見せたいノートほど後に作る**こと。おすすめの作成順は、このファイルの逆順（10→1）で、最後に作る「1. ようこそ」を一番上に
- エディタ画面の撮影用には、最初に開くノートを「2. Markdown記法サンプル」にすると、プレビュー機能が一番伝わる
- タグはノートごとに付け分けてあるので、一覧のタグ表示やタグ絞り込みの撮影にも使える
- 件数の目安：一覧が画面の下まで自然に埋まるのは **8〜10件**。このセットは10件分ある

## 10. 長文サンプル（スクロール撮影用）

タグ案：日記

```text
朝の散歩コースの話（長文サンプル）

朝の空気が気持ちいい季節になってきたので、近所の散歩コースをあらためて歩いてみた記録です。

駅前の大通りを抜けて川沿いの道に出ると、景色が急に開けます。水面が朝日を反射して光っていて、対岸の山並みがくっきり見える日は、それだけで少し得した気分になります。

途中にある小さな公園では、決まった時間に体操をしている人たちがいて、ラジオの音がかすかに聞こえてきます。その脇を通り抜けて、商店街のシャッターが上がり始める頃に折り返すのが最近の定番コースです。

歩く速度や体調によって、30分で帰ってくる日もあれば、寄り道して1時間近くになる日もあります。帰ってきたら、その日の様子をこうして数行だけ残しておくと、後で季節の移り変わりが分かって面白いです。

このノートは、長い文章を書いたときにエディタがどう見えるかを確認するためのサンプルも兼ねています。スクロールしても書き続けられること、行間が読みやすいことが、メモアプリでは地味に大事なポイントだと思っています。
```
