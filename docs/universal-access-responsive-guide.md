# ユニバーサルアクセス・レスポンシブUI対応ドキュメント

## 概要
これまでデスクトップ表示（Mac等）のみを中心に開発していたため、スマートフォン等の画面幅が狭い端末でアクセスした際に、画面レイアウトの崩れやメモエディタが見えない、一覧に戻れないといった問題が発生していました。
本ドキュメントでは、あらゆるデバイスから快適に操作できる「ユニバーサルアクセス」を目指したレスポンシブUI実装の記録をまとめます。

---

## 1. 発生していた課題
1. **小画面（スマホ）でエディタが表示されない**:
   - Bootstrapの `col-md-4` / `col-md-8` により、スマホ表示時には縦並び（スタック）になり、メモ一覧が最上部を占有してエディタが見えない状態になっていた。
2. **メモ一覧に戻れない**:
   - メモを開いた後、スマホ画面から一覧に戻る導線（ボタン）が存在しなかった。

---

## 2. 実装したレスポンシブUI構成
画面幅（768px未満のモバイル / 768px以上のデスクトップ）に応じて、表示状態を動的に切り替える仕組みを導入しました。

- **PC/タブレット (幅 >= 768px)**:
  - 従来通り「左側：メモ一覧」「右側：ノート詳細・エディタ」を同時に横並び表示。
- **スマートフォン (幅 < 768px)**:
  - メモ一覧表示時：一覧を全画面表示。
  - ノート選択時：ノート詳細・エディタ画面を全画面表示。
  - ヘッダーに `[ ← 一覧へ ]` ボタンを追加し、タップでいつでも一覧に切り替え可能。

---

## 3. コードの変更ポイント (`simplenote-clone/app/page.tsx`)

### モバイル一覧表示フラグの導入
```tsx
const [mobileShowList, setMobileShowList] = useState<boolean>(false);
```

### レスポンシブクラスと条件分岐
```tsx
{/* 左側：メモ一覧 */}
<div className={`col-md-4 border-end d-flex flex-column h-100 ${selectedNoteId && !mobileShowList ? 'd-none d-md-flex' : 'd-flex'}`}>
  ...
</div>

{/* 右側：エディタ */}
<div className={`col-md-8 d-flex flex-column h-100 bg-body ${selectedNoteId && !mobileShowList ? 'd-flex' : 'd-none d-md-flex'}`}>
  ...
</div>
```

---

## 4. 自動選択ループの解決 (トラブルシューティング)
詳細については `docs/troubleshooting/2026-10-21-mobile-back-button-issue.md` を参照してください。

- **問題**: 「一覧へ」ボタンを押して `selectedNoteId` を `null` にしても、`useEffect` がそれを検知して即座に `notes[0]` を自動選択してしまい、一瞬でエディタに戻ってしまう問題。
- **対策**: `mobileShowList` フラグが `true` のときは自動選択をスキップするようフックを修整。
